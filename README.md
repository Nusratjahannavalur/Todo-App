# Todo-App
Project: ToDo Application Website
The ToDo Application Website is a web-based task management platform that enables users to create, update, delete, and track their daily tasks efficiently. Built using Advanced Java (Servlets, JSP, JavaBeans) and JDBC, the application follows the MVC architecture for clean code structure. It incorporates secure user authentication using HTTP Sessions, stores data in a MySQL database, and features a user-friendly interface built with JSP, HTML, CSS, Bootstrap, and JavaScript. The project uses Apache Maven for dependency management and Tomcat Server for deployment.

<h4>🛠 Tech Stack</h4>
Backend: Java (Servlets, JSP, JavaBeans), JDBC<br>
Frontend: HTML, CSS, JavaScript, JSP, Bootstrap<br>
Database: MySQL<br>
Server: Apache Tomcat<br>
Build Tool: Maven<br>
Session Management: HTTP Sessions<br>
IDE: Eclipse<br>
